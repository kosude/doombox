DETAILED TIMING PARAMETERS FOR 320x400 @ (close enough to) 60Hz

----------------------------------- GENERAL -----------------------------------

    Hor pixels      = 320               (400 including non-addressable)
    Ver lines       = 400               (455 including non-addressable)

    Hor freq        = 31.448    kHz         = 31.8  usec/line
    Ver freq        = 69.113     Hz         = 14.5  msec/frame
    Pixel clock     = 12.579    MHz         = 79.5  nsec/pixel

    Scan type       = non-interlaced
    Hor sync polar  = neg               (i.e. active low)
    Ver sync polar  = pos               (i.e. active high)

    Hor blank start = 25.440    usec        = 320   pixels

    Hor sync start  = 32.435    usec        = 408   pixels

    Ver total time  = 14.469    msec        = 455   lines

    Ver blank start = 13.514    msec        = 425   lines
    Ver blank time  =  0.827    msec        =  26   lines
    Ver sync start  = 13.642    msec        = 429   lines
